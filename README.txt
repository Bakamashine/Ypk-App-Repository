Чтобы начать работать с api надо запусить данный проект.
После откроесть консолька в которой будет путь (покачто https://localhost:7001) его нужно скопировать в вставить в строку с ссылкой в браузере.
После этого откроеся swagger где показано какие данные данные отправлять, какие данные получаем на выходе и по какому пути надо обращаться к ендпоинту (основной обработчик данных).
Там открываем интересующий нас ендпоинт и смотрим как с ним работать.
Там показывается каой объект надо отправлять, какой у него должен быть тип данных, а так же как именно отправлять данные в запросе
(в body или в form это написанноу справой стороны в строке Request body, если написано multipart/form-data значит данные надо отправлять в форме, если application/json, то отправляем в теле запроса) 
Ниже будет показанно что может возвращаться и какой код (200 401 204 и тд) и что этот код будет означать
На клиенте при обращении к api указываем путь к нужному ендпоинту, потом прикладываем необходимые данные, после получения отвера надо десериализовать данные и раскидать из по переменным, с которыми уже можно работать.
